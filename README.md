## Whoami

I break into systems for a living, with permission. Almost everything I know
is self-taught. I started on HN Community, an Indonesian underground forum that
used to be the biggest gathering spot for hacker newbies in the country, and I
never really left the terminal after that. Debian has been my daily driver
since 2013, and I care about GNU/Linux and open source in general.

Between client pentests I keep a lab habit: HackTheBox, TryHackMe, Red Team
Labs, HackMyVM, and Root Me. I also report vulnerabilities in open source
software and get them assigned CVE IDs. 100+ CVEs credited so far, listed on
Wordfence Threat Intel and Patchstack.

Outside of security I watch Neon Genesis Evangelion and My Hero Academia, and
I still back Cristiano Ronaldo.
